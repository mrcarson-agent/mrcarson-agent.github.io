Privacy Policy

Mr Carson Mail Reader — last updated November 2, 2026.

Who uses this app

This app is a private tool used only by its owner, on the owner's own computer. It is not offered to other people.

What it accesses

With the owner's permission, it requests read-only access to the owner's own Gmail account (the gmail.readonly permission). It cannot send, delete, or change any email.

How data is used and stored

Email content is read on the owner's computer only, to extract dates, deadlines and notes. It is not sent to, shared with, or sold to any third party, and it is not used for advertising. The sign-in token is stored in a private, owner-only file on the owner's computer.

Google API Services User Data Policy

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

The owner can revoke access at any time at myaccount.google.com/permissions.
